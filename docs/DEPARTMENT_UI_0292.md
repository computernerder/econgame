# Internal department configuration — 0.29.2

Home office now starts with an **Internal departments** section above the service queue and company-finance setup. A prominent **Add / configure department** button opens the configuration form. Every existing department has its own **Edit department** and role-specific **Hire staff** links, alongside actual assigned staff, coverage, tools and latest daily capacity. The setup form is adjacent to that table and opens automatically when there are no departments.

Edit links target the saved department ID and load its provider, role, employees, tool level, counties, industry expertise and existing leader. Provider and role are fixed when editing that specific record. The general configuration form reloads saved settings when its company or department changes, and shows only employees belonging to that company and role. Selected former employees remain visible with their status so an edit does not silently discard saved assignments. Empty staff selection retains the existing all-qualified-role-staff behavior.

The form distinguishes a new department from an existing one, explains tool upgrade costs, and links to hiring for the selected role. No staff in that role produces an explicit capacity warning. Changing selectors loads a different saved configuration; unsaved edits to the previous selection are not retained. Unknown/unavailable department edit links show a notice and do not silently open another department for editing.

Existing service simulation, tools pricing, queues, qualifications, payroll, coverage rules and internal financial settlement are unchanged. Department creation does not grant benefits without staff and work. Re-saving unchanged tools incurs no additional tool charge. The existing configure action still resets the last daily capacity counters until delivery recalculates them; it does not promise immediate service capacity. No saved-game migration or live campaign edit is required.
